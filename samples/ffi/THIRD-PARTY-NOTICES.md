# Utah teapot data

The patch indices and control points in `teapot.fss` are adapted from
[three.js TeapotGeometry.js](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/geometries/TeapotGeometry.js).
The Utah teapot model was created by Martin Newell. Tessellation code in this sample is implemented in FScript.
